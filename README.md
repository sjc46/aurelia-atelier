# Aurelia Atelier

A private desk for creators. One brief becomes a content pack, then a vertical film.

## Rooms

- **Atelier** — the floor, and the commissions worth making
- **Signals** — niches scored for yield, not noise
- **Generate** — hooks, caption, script, on-screen lines, a five-part series
- **Reel** — films that pack into a 9:16 WebM, 12, 18, or 24 seconds, with a quiet score
- **Desk** — a single typeset piece
- **Library** — what you keep, stored in this browser
- **Week** — a restrained slate

## Run

Open `index.html` in a browser. No build, no server.

The reel is composed in the browser (canvas + MediaRecorder) and downloads as WebM. Chrome or Edge is the surest room for filming.
